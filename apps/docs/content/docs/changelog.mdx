## v3.2 存档加固与测试基建

- **core 崩溃安全存档原语(`saveFiles`)**:业务无关的"原子文件 + 轮换备份"层 —— 临时写入 → fsync → 读回校验 → 备份轮换 → 原子重命名,配合信封校验(magic + 长度 + SHA-256)抓物理损坏;不含存档头部业务字段。`AtomicFileBackend` 六原语接口(`writeFile`/`syncFile`/`renameFile`/`readFile`/`deleteFile`/`exists`)由 core 编排但不实现;`commitSlot` 保证任意时刻中断 `path` 都指向完整的一代,`recoverSlot` 按 current → backup1 → backup2 新到旧扫描,返回首个通过校验的一代及每一代的失败原因
- **两个后端实现**:新包 `adapters-savefile`(Tauri 桌面壳)—— `createTauriSaveFileBackend()` + 配套 Rust 插件 crate `overworld-savefile`(crates.io 单独发布)提供真正的 `fsync`(Tauri 官方 plugin-fs 的 JS API 不暴露此能力),`resolve_path` 拒绝绝对路径与 Windows 根路径;`platform` 新增 `createWebSaveFileBackend()`(localStorage 实现,`syncFile` 为 no-op —— 浏览器没有 fsync 等价物)
- **core `createSeededRng`/`RngSource`**:零依赖确定性 PRNG(mulberry32),任何工厂函数都可接受注入的随机源 —— 生产传 `{ next: Math.random }`,测试传固定种子得到字节级可复现结果
- **新包 `@overworld-engine/test-kit`**:应用层集成测试原语 —— `createEventRecorder`(基于 `EventBus.onAny` 的确定性事件流录制断言)+ `renderHook`(react-test-renderer 挂载单个 hook,无 DOM/Canvas/WebGL,验证 hook→action 接线);非渲染/E2E 框架
- **流程修复**:CI 新增 changeset 强制检查(PRs 改动 `packages/*/src`/`src-tauri` 必须带 changeset,`pnpm changeset --empty` 可显式豁免);全部 27 包的 CHANGELOG 按 git 发布史回填,npm 已发布版本与 changelog 条目一一对应

## v3.1 Steam 桌面适配(新包 adapters-steam)

## v3.0 UI 扩展性重构(破坏性)

## v2.0 世界生产化(world-production v2)

- **core `inputLock`**:无头、框架无关的输入锁(`acquire`/`release`/`isLocked`/`activeLocks`/`subscribe`/`releaseAll`)+ `createInputLock()` 隔离实例 + `input:lock-changed` 总线事件 —— input(键盘层、摇杆)与 scene(Player、交互、FollowCamera 轨道)统一向它查询,一次 `inputLock.acquire('dialogue')` 即全局挂起游戏输入,无需逐源接线
- **scene(major)**:实例化 `Decorations` 渲染器;运行时 `Lod` + `lods` 配置;`FollowCamera` 轨道相机;ref 驱动的移动 NPC(`SceneShell.npcPositionRefs` 驱动 `BaseNPC` 的视觉/碰撞体/邻近/选中环,`BaseNPC.positionRef`;独立移动 NPC 用 `AgentNPC`);`isInputBlocked` 省略时回退到 `inputLock.isLocked()`
- **input**:`useKeyboardLayer` 接受 `{ lockInput }` 选项(层存活期持有共享 inputLock;导出 `parseLayerOpts`);`<VirtualJoystick respectInputLock>`(默认 true)持锁时输出清零(纯函数 `resolveJoystickOutput`)
- **audio**:命名总线(`master`/`music`/`ambience`/`sfx`,`setBusVolume`/`getBusVolume`);基于距离的环境音区(`setAmbientZones`/`updateListener` + 纯函数 `zoneWeight`/`mixBuses`);定位单发 `playCue`;测试/无头环境用 `silentBackend`
- **environment**:`<WorldEnvironment preset engine quality>` —— 质量感知的天空/雾/地面/光照/星空层,`WORLD_ENV_PRESETS`(`clear-noon`/`overcast`/`foggy-dusk`/`night`)+ 纯函数 `resolvePreset`/`resolveLight`;传入 engine 时环境光/日光随其时间逐帧插值
- **loading**:场景级加载状态 `useSceneLoadStore`(相位 `idle → module → geometry → texture → first-frame → ready`,`SCENE_PHASES`/`aggregateSceneProgress`);区域流式加载(`useZoneStreaming`/`orderZonesByDistance`,`ZoneManifest`/`ZoneBounds`);`<FirstFramePhase />` Canvas 标记;`installSceneLoadDebugHandle()`(开发构建下 Playwright 友好的 `window.__overworldSceneLoad` 检查句柄)
- **minimap**:玩家相对 HUD 雷达选择器 —— `selectRadarMarkers`(世界实体 → 旋转/距离钳制的标记)与 `computeOffscreenIndicator`(超程实体的屏幕边缘角),`RadarConfig`/`RadarMarker`/`RadarEntity` 类型
